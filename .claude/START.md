# Inicio del Proyecto

Antes de escribir cualquier línea de código debes:

1. Revisar CLAUDE.md

2. Revisar PROJECT_CONTEXT.md

3. Revisar TASKS.md

4. Revisar ARCHITECTURE.md

5. Revisar DATABASE.md

6. Revisar API.md

Nunca generes código sin revisar esos archivos.

Si alguno no existe, créalo antes de continuar.

Trabaja siempre módulo por módulo.

No reconstruyas funcionalidades ya existentes.

Al finalizar cada tarea:

- Actualiza TASKS.md
- Actualiza ROADMAP.md
- Documenta los cambios.

## Flujo de Trabajo

1. Leer el contexto.
2. Analizar la tarea.
3. Desarrollar únicamente el módulo solicitado.
4. Actualizar TASKS.md.
5. Actualizar ROADMAP.md.
6. Explicar los archivos creados o modificados.
