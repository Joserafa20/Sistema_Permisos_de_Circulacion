# CODING STANDARDS

## Lenguaje

TypeScript

---

## Backend

NestJS

Un módulo por dominio.

Controllers limpios.

Toda lógica en Services.

Acceso BD mediante Repository.

DTO obligatorios.

Swagger obligatorio.

---

## Frontend

React

Next.js

Componentes reutilizables.

Hooks personalizados.

No lógica de negocio en componentes.

---

## Base de Datos

Migraciones.

No SQL embebido.

Usar ORM.

---

## Código

Funciones pequeñas.

Nombres descriptivos.

Comentarios solo cuando sean necesarios.

No duplicar código.

Seguir principios SOLID.
