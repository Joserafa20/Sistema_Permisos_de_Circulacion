# Metodología de Desarrollo

El desarrollo del proyecto será incremental.

## Reglas

- Nunca desarrollar un Sprint completo en una sola ejecución.
- Desarrollar únicamente una tarea principal a la vez.
- Antes de escribir código, presentar el plan técnico.
- Esperar aprobación del usuario antes de implementar.
- Al finalizar cada tarea:
  - Ejecutar una auto revisión.
  - Actualizar TASKS.md.
  - Actualizar ROADMAP.md.
  - Documentar los archivos creados y modificados.
  - Identificar riesgos o mejoras detectadas.
- No continuar automáticamente con la siguiente tarea.
- Esperar siempre autorización del usuario para continuar.
